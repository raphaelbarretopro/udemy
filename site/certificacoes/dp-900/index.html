O que é a DP-900

A Microsoft Certified: Azure Data Fundamentals é uma certificação de nível Fundamentals da trilha Dados e analytics. Conceitos de dados relacionais, não relacionais e analytics, e os serviços de dados do Azure.

Como se preparar

Foque em vocabulário, categorias de serviço, casos de uso e no “quando usar o quê”. A prova cobra entendimento, não configuração.

  1. Leia o guia de estudoEle lista cada habilidade cobrada. Use a seção acima como mapa.
  2. Faça a trilha do Microsoft LearnOs módulos gratuitos cobrem todo o conteúdo oficial.
  3. Treine com simuladosQuestões no formato real mostram onde você ainda erra.
  4. Agende quando passar com folgaMire em 800+ nos simulados antes de marcar a prova.

Plano de estudo da DP-900 em 5 semanas

Ritmo pensado para cerca de 1 hora por dia. Se você já trabalha com o assunto, junte semanas; se está começando do zero, estique.

SemanaO que estudarComo praticar
Semana 1Conceitos de dadosDados estruturados, semiestruturados e não estruturados, formatos de arquivo (CSV, JSON, Parquet), processamento transacional (OLTP) x analítico (OLAP), e os papéis em dados: administrador de banco, engenheiro e analista.Pegue um mesmo conjunto de dados e salve em CSV, JSON e Parquet; compare tamanho e legibilidade.
Semana 2Dados relacionais no AzureTabelas, chaves, normalização, SQL básico (SELECT, INSERT, UPDATE, DELETE, JOIN), visões, índices e procedimentos. Azure SQL Database, Instância Gerenciada de SQL, SQL Server em VM e os bancos de código aberto gerenciados (PostgreSQL e MySQL).Crie um Azure SQL Database com o banco de exemplo e escreva consultas com JOIN e GROUP BY.
Semana 3Dados não relacionaisAzure Blob Storage, Data Lake Storage, Azure Files e Table Storage. Azure Cosmos DB e suas APIs (NoSQL, MongoDB, PostgreSQL, Apache Cassandra, Table, Apache Gremlin).Crie uma conta do Cosmos DB no nível gratuito e grave alguns documentos JSON.
Semana 4AnalyticsIngestão e ETL, data warehouse x data lake x lakehouse, Microsoft Fabric, Azure Databricks, analytics em tempo real e visualização com o Power BI.Abra uma avaliação do Microsoft Fabric e carregue um arquivo num lakehouse; depois crie um relatório simples.
Semana 5Revisão e simuladosConceitos fundamentais e analytics são as áreas de maior peso.Faça simulados e revise principalmente a diferença entre os serviços de banco de dados.

O que mais confunde na prova DP-900

OLTP x OLAP

OLTP registra muitas transações pequenas do dia a dia (vendas, cadastros). OLAP consulta grandes volumes de dados históricos para análise e relatórios.

Azure SQL Database x Instância Gerenciada x SQL em VM

O SQL Database é o mais gerenciado e serve a um banco. A Instância Gerenciada tem compatibilidade quase total com o SQL Server, ideal para migrar. O SQL em VM dá controle total do sistema operacional e do SQL Server.

Data lake x data warehouse x lakehouse

O lake guarda arquivos brutos de qualquer formato. O warehouse guarda dados estruturados e prontos para consulta SQL. O lakehouse junta os dois: arquivos no lake com recursos de tabela e SQL por cima.

Lote x tempo real

Em lote, os dados são processados em intervalos (a cada hora, a cada dia). Em tempo real (streaming), cada evento é processado assim que chega.

Dica para o dia da prova: Muitas questões pedem o serviço certo para um tipo de dado. Classifique o dado primeiro (relacional, documento, arquivo, evento) e só depois olhe as alternativas.

A DP-900 vale a pena?

Vale a pena para quem quer começar em dados (análise, engenharia ou banco de dados), para desenvolvedores que precisam entender as opções de banco no Azure e para profissionais de negócio que trabalham com BI. Não exige experiência e não expira. Quem já trabalha com bancos de dados pode ir direto para uma certificação Associate.

DP-900 ou PL-300?

A DP-900 dá a visão geral de dados no Azure: tipos de dados, bancos relacionais e não relacionais e analytics. A PL-300 é prática e focada no Power BI.

Se você quer ser analista de dados e já usa Excel, pode ir direto para a PL-300; a DP-900 ajuda a entender de onde vêm os dados que você vai analisar.

Se você quer seguir para engenharia de dados (DP-600, DP-700) ou administração de banco (DP-300), comece pela DP-900.

Perguntas frequentes sobre a DP-900

A prova DP-900 tem em português?

Sim. A prova DP-900 pode ser feita em português do Brasil, no centro de provas ou online, com supervisão remota.

Quanto tempo dura a prova DP-900 e qual a nota para passar?

A prova DP-900 dura 45 minutos e a nota mínima para passar é 700, numa escala de 1 a 1000.

Precisa de pré-requisito para a DP-900?

Não. A DP-900 não tem pré-requisito e é um ponto de partida: dá para fazer sem nenhuma certificação anterior.

A certificação DP-900 expira?

Não. As certificações Fundamentals, como a DP-900, não expiram.

O que mais cai na prova DP-900?

As áreas com mais peso na DP-900 são “Descrever conceitos fundamentais de dados” (25–30%) e “Descrever uma carga de trabalho de analytics” (25–30%). Ao todo, a prova cobre 4 áreas.

Qual certificação fazer depois da DP-900?

Depois da DP-900, os caminhos mais comuns são PL-300 (Analista de dados do Power BI), DP-300 (Administrador de banco de dados do Azure), DP-600 (Engenheiro de analytics do Fabric), DP-700 (Engenheiro de dados do Fabric).
