O que é a AZ-401

A Microsoft Certified: Agentic DevOps Engineer Expert é uma certificação de nível Expert da trilha Desenvolvimento e DevOps. A nova geração do DevOps Expert: Azure DevOps, GitHub Actions e agentes de IA no ciclo de entrega. Chega enquanto a AZ-400 se aposenta.

O que cai na prova

Áreas de conhecimento e pesos oficiais do guia de estudo da Microsoft. Quanto maior o peso, mais questões.

  • Métricas de sucesso
  • Colaboração

Projetar e implementar a estratégia de controle de código

10–15%
  • Branches no Azure DevOps e GitHub
  • Repositórios
03

Projetar e implementar pipelines de build e release

35–40%
  • Pacotes
  • Testes em pipelines e GitHub Actions
  • Pipelines e implantações
04

Projetar e implementar o plano de segurança e conformidade

15–20%
  • Autenticação e autorização
  • Informações sensíveis em automação
  • Varredura automatizada
05

Implementar a estratégia de instrumentação

15–20%

  • Monitoramento com agentes de IA
  • Análise de métricas com agentes de IA

Como se preparar

Espere cenários longos e decisões de arquitetura com trade-offs. Revise requisitos de custo, segurança e disponibilidade em cada escolha.

  1. Leia o guia de estudoEle lista cada habilidade cobrada. Use a seção acima como mapa.
  2. Faça a trilha do Microsoft LearnOs módulos gratuitos cobrem todo o conteúdo oficial.
  3. Treine com simuladosQuestões no formato real mostram onde você ainda erra.
  4. Agende quando passar com folgaMire em 800+ nos simulados antes de marcar a prova.
