O que é a AZ-802

A Microsoft Certified: Windows Server Administrator Associate é uma certificação de nível Associate da trilha Azure e infraestrutura. Administrar Windows Server em ambientes locais e híbridos: AD DS, VMs, armazenamento, rede e segurança. Substitui AZ-800 e AZ-801.

Para quem é

Administradores de servidores Windows que gerenciam ambientes locais integrados ao Azure.

O que cai na prova

Áreas de conhecimento e pesos oficiais do guia de estudo da Microsoft. Quanto maior o peso, mais questões.

01

Implantar e gerenciar o AD DS

20–25%
  • Ambientes multisite, multidomínio e multifloresta
  • Entidades de segurança
  • Políticas de grupo
02

Gerenciar instâncias e cargas do Windows Server em ambiente híbrido

10–15%
  • Gerenciamento remoto
  • Serviços do Azure para servidores híbridos
  • Hyper-V e VMs no Azure
03

Gerenciar máquinas virtuais

10–15%
04

Implementar redes locais e híbridas

10–15%
  • Resolução de nomes
  • Endereçamento IP
05

Gerenciar armazenamento e serviços de arquivos

15–20%
  • Azure Files
  • Compartilhamentos de arquivos
  • Armazenamento do Windows Server
06

Proteger a infraestrutura do Windows Server

10–15%
  • Sistema operacional
  • AD DS
07

Monitorar e solucionar problemas

15–20%
  • Ferramentas do Windows Server e do Azure
  • Problemas do Windows Server
  • Active Directory
