O que é a AI-200

A Microsoft Certified: Azure AI Cloud Developer Associate é uma certificação de nível Associate da trilha Desenvolvimento e DevOps. Desenvolver soluções na nuvem com contêineres, bancos de dados do Azure, mensageria e Functions, com foco em IA.

Para quem é

Desenvolvedores que constroem e mantêm aplicações modernas e com IA no Azure.

O que cai na prova

Áreas de conhecimento e pesos oficiais do guia de estudo da Microsoft. Quanto maior o peso, mais questões.

01

Desenvolver soluções em contêineres no Azure

20–25%
  • Hospedagem de aplicações em contêiner
  • Orquestração de contêineres
02

Desenvolver soluções de IA com serviços de dados do Azure

25–30%
  • Cosmos DB for NoSQL
  • Azure Database for PostgreSQL
  • Azure Managed Redis
03

Conectar e consumir serviços do Azure

20–25%
  • Soluções orientadas a eventos e mensagens
  • Azure Functions
04

Proteger, monitorar e solucionar problemas

20–25%
  • Soluções seguras
  • Monitoramento e troubleshooting

Como se preparar

Combine teoria com prática: crie uma conta gratuita ou use os laboratórios do Microsoft Learn e execute as tarefas de cada domínio.

  1. Leia o guia de estudoEle lista cada habilidade cobrada. Use a seção acima como mapa.
  2. Faça a trilha do Microsoft LearnOs módulos gratuitos cobrem todo o conteúdo oficial.
  3. Treine com simuladosQuestões no formato real mostram onde você ainda erra.
  4. Agende quando passar com folgaMire em 800+ nos simulados antes de marcar a prova.
