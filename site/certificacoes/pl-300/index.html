O que é a PL-300

A Microsoft Certified: Power BI Data Analyst Associate é uma certificação de nível Associate da trilha Dados e analytics. Preparar, modelar, visualizar e proteger dados com o Power BI, incluindo DAX.

Para quem é

Analistas de dados e de negócio que constroem relatórios e dashboards.

O que cai na prova

Áreas de conhecimento e pesos oficiais do guia de estudo da Microsoft (versão de 20 de abril de 2026). Quanto maior o peso, mais questões.

01

Preparar os dados

25–30%
  • Conexão a fontes
  • Perfil e limpeza
  • Transformação e carga
02

Modelar os dados

25–30%
  • Modelo de dados
  • Cálculos com DAX
  • Desempenho do modelo
03

Visualizar e analisar os dados

25–30%
  • Relatórios
  • Usabilidade e storytelling
  • Padrões e tendências
04

Gerenciar e proteger o Power BI

15–20%
  • Workspaces e itens
  • Segurança e governança

Como se preparar

Combine teoria com prática: crie uma conta gratuita ou use os laboratórios do Microsoft Learn e execute as tarefas de cada domínio.

  1. Leia o guia de estudoEle lista cada habilidade cobrada. Use a seção acima como mapa.
  2. Faça a trilha do Microsoft LearnOs módulos gratuitos cobrem todo o conteúdo oficial.
  3. Treine com simuladosQuestões no formato real mostram onde você ainda erra.
  4. Agende quando passar com folgaMire em 800+ nos simulados antes de marcar a prova.
